# BPSC Quiz Bot

**BPSC Quiz Bot** — Telegram के लिए एक professional, long-polling based quiz bot starter repo।  
Ye repo BPSC Civil Services (Prelims/Mains objective practice) के लिए tailored है: question bank, quiz sessions, leaderboards, admin import tools, और Railway-ready deployment setup।

---

## 🔧 फीचर्स (Starter)
- User registration (Telegram user)
- Quick quiz (10 Qs) — timed/practice mode (starter)
- Question bank with syllabus tags (subject, topic, stage)
- Store quiz attempts & scores (SQLite by default; PostgreSQL supported)
- Admin import JSON script (`import_questions.py`)
- Daily quiz stub (background thread)
- Railway friendly (Background Worker)
